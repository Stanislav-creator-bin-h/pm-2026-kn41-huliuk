## 5. Lessons learned

| Що спрацювало | Що не спрацювало | Що зробили б інакше |
| --- | --- | --- |
| Жорсткий Definition of Done (DoD) із критеріями безпеки та code review повністю виключив потрапляння дефектів подвійного бронювання в реліз. | Спроба довірити генерацію фінансового кошторису штучному інтелекту дала критичну помилку в ставках та резервах. | Одразу б розраховували фінансову модель вручну за формулами, використовуючи AI суто для форматування розмітки. |
| Гібридний підхід (T&M with Cap на 570 000 грн) дав гнучкість команді адаптувати пріоритети без бюрократичних затримок. | Розрахунок на те, що зовнішній API розкладу буде готовий у першому спринті, не справдився через затримки навчальної частини. | На першому ж тижні спроектували б проміжний адаптер файлового обміну (CSV/JSON) замість очікування live API. |
